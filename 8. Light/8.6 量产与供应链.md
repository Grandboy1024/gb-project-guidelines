产品研发完成后，需要建立完整的生产体系。

## 5.1 供应链管理

需要寻找和管理以下供应商：

| 供应商 | 负责内容 |
| :--- | :--- |
| LED 供应商 | LED 灯珠、灯板 |
| 电源供应商 | AC/DC 电源、驱动电源 |
| PCBA 厂 | PCB 制造与 SMT |
| MCU 供应商 | 主控芯片、无线模组 |
| 结构厂 | 外壳、支架、散热件 |
| 模具厂 | 注塑、压铸模具 |
| 包装厂 | 彩盒、说明书、内衬 |
| 组装厂 | 整机组装与测试 |

建议建立完整 BOM（物料清单），不仅记录物料名称，还需要记录：
- 物料编码。
- 规格型号。
- 品牌及供应商。
- 单价。
- 最小起订量。
- 交期。
- 替代料。
- 关键质量要求。

## 5.2 生产流程

以智能灯为例：

**智能灯生产流程**
1. PCB SMT 贴片
2. PCBA 电气测试
3. 固件烧录
4. 无线通信测试
5. LED 光学测试
6. 结构件与灯具组装
7. 整机功能测试
8. 老化测试
9. 防水及外观抽检
10. 包装、贴标、装箱
11. 成品入库

这里特别建议建立一个统一的设备身份管理体系。

每台灯具在生产时应该具有：
- 唯一 Device ID。
- 产品型号 Model。
- 硬件版本 Hardware Version。
- 固件版本 Firmware Version。
- 蓝牙 MAC 地址。
- Wi-Fi MAC 地址（如适用）。
- SN 序列号。
- 生产批次。

生产烧录时，要把设备身份、型号和固件版本正确关联起来。

如果未来公司有多种外观，但共用同一套硬件平台，也要提前规划产品型号和外观 SKU 的映射关系。

## 5.3 建立生产测试系统

不能只依赖人工拿手机测试。

建议开发一个生产测试工具，实现：
1. 扫描设备。
2. 识别产品型号。
3. 读取设备信息。
4. 测试 LED 开关。
5. 测试亮度。
6. 测试传感器。
7. 测试蓝牙。
8. 测试 Wi-Fi。
9. 验证固件版本。
10. 生成 PASS/FAIL 结果。

同时建立生产测试记录，确保后续发生售后问题时，可以追溯生产批次。
