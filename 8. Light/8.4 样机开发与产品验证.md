# 样机开发与产品验证

这部分建议采用业内常见的三个阶段：

## 1.1 EVT — Engineering Validation Test

> **工程验证**：主要验证设计能不能工作

- PCB 能否正常运行
- LED 驱动是否稳定
- 蓝牙和 Wi-Fi 是否正常
- APP 是否能控制设备
- 结构是否能正常组装
- 电源、散热是否符合设计要求

## 1.2 DVT — Design Validation Test

> **设计验证**：主要验证产品设计是否成熟

- 高低温测试
- 防水测试
- 跌落测试
- 老化测试
- 无线通信距离测试
- 长时间运行测试
- APP 兼容性测试
- OTA 升级测试

## 1.3 PVT — Production Validation Test

> **生产验证**：主要验证能不能稳定量产

- 小批量生产
- 生产工艺验证
- 工装夹具验证
- 自动化测试验证
- 烧录流程验证
- 包装测试
- 成品抽检

# 二、联调说明

这里有一个特别重要的问题：APP、固件和硬件不能只在最终阶段才进行联调。

EVT 阶段就完成第一轮完整联调：`手机 APP → 蓝牙发现 → Wi-Fi 配网 → 灯具控制 → 状态同步`。否则，可能出现硬件已经定型，但 APP 协议、设备识别、配网流程需要大规模修改的情况。
