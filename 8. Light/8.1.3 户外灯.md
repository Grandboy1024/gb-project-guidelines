# 二、各类户外灯具详细介绍

## 2.1 Decorative Lighting Projectors（装饰投影灯）

**Amazon 分类链接：**

https://www.amazon.com/Best-Sellers-Tools-Home-Improvement-Decorative-Outdoor-Lighting-Projectors/zgbs/hi/17171449011/

### 产品定义

装饰投影灯通过 LED、激光或其他光学系统，将图案、颜色、动态效果投射到墙面、地面、建筑物或其他表面上。

主要用于装饰，而不是提供大范围基础照明。

### 常见产品类型

| 产品类型 | 英文 | 产品特点 |
|---|---|---|
| 激光投影灯 | Laser Projector | 投射红色、绿色等激光光点或图案 |
| LED 图案投影灯 | LED Pattern Projector | 投射雪花、星星、图案等 |
| 节日投影灯 | Holiday Projector | 圣诞节、万圣节等节日装饰 |
| 星空投影灯 | Star Projector | 投射星空、星点效果 |
| 水纹投影灯 | Water Wave Projector | 模拟水波、动态流动效果 |
| 建筑投影灯 | Architectural Projector | 在建筑外墙投射装饰图案 |

### 适用场景

- 房屋外墙
- 庭院
- 圣诞节装饰
- 万圣节装饰
- 派对
- 商业建筑
- 节日活动

### 主要技术参数

| 参数 | 英文 | 说明 |
|---|---|---|
| 光源类型 | Light Source | LED、Laser |
| 投影距离 | Projection Distance | 灯具与投影表面的距离 |
| 投影范围 | Projection Coverage | 可以覆盖的面积 |
| 投影角度 | Projection Angle | 投射方向和角度 |
| 图案数量 | Pattern Count | 支持的图案数量 |
| 动态效果 | Dynamic Effects | 是否支持旋转、闪烁、变化 |
| 控制方式 | Control Method | 按键、遥控器、APP |
| 防护等级 | IP Rating | 户外防水防尘能力 |

### 开发注意事项

1. 关注投影清晰度和图案效果。
2. 测试不同投影距离下的清晰度。
3. 关注投影角度和覆盖范围。
4. 关注镜头和光学组件的防水设计。
5. 激光类产品需要特别关注激光安全等级及适用法规。
6. 节日投影产品需要考虑定时、动态效果和遥控功能。

## 2.2 Flood & Security Lights（泛光灯与安防灯）

**Amazon 分类链接：**

https://www.amazon.com/Best-Sellers-Tools-Home-Improvement-Flood-Lights/zgbs/hi/495238/

### 产品定义

泛光灯（Flood Light）主要提供大面积照明。

安防灯（Security Light）主要用于提高户外区域夜间可见度，通常配合人体感应、光控或摄像头使用。

两者存在较大重叠，但产品定位有所不同。

### 常见产品类型

| 产品类型 | 英文 | 产品特点 |
|---|---|---|
| 普通 LED 泛光灯 | LED Floodlight | 大范围高亮度照明 |
| 太阳能泛光灯 | Solar Floodlight | 太阳能板供电，内置电池 |
| 人体感应灯 | Motion Sensor Light | 检测人体移动后自动点亮 |
| 多灯头安防灯 | Multi-Head Security Light | 多个可调节灯头 |
| 双灯头泛光灯 | Dual Head Floodlight | 两个独立调节灯头 |
| 三灯头泛光灯 | Triple Head Floodlight | 三个独立调节灯头 |
| 摄像头安防灯 | Security Camera Floodlight | 集成摄像头和照明 |
| Wi-Fi 安防灯 | Wi-Fi Security Light | 支持 APP 远程控制 |

### 适用场景

- 车库
- 车道
- 房屋外墙
- 后院
- 仓库
- 停车场
- 房屋入口
- 户外安防区域

### 主要技术参数

| 参数 | 英文 | 说明 |
|---|---|---|
| 光通量 | Luminous Flux | 整灯输出流明 |
| 输入功率 | Input Power | 灯具实际功耗 |
| 光效 | Luminous Efficacy | 每瓦产生的流明 |
| 光束角 | Beam Angle | 光线覆盖范围 |
| 色温 | CCT | 暖白、自然白、冷白 |
| 感应距离 | Detection Range | 人体感应最大距离 |
| 感应角度 | Detection Angle | 感应覆盖角度 |
| 延迟时间 | Time Delay | 触发后保持亮灯的时间 |
| 防护等级 | IP Rating | 防尘防水能力 |
| 电池容量 | Battery Capacity | 太阳能或电池款的储能能力 |

### 开发注意事项

1. 不能只关注 LED 数量，需要测试整灯实际光通量。
2. 关注光束角和实际照射范围。
3. 优化 PIR 人体感应器的距离和角度。
4. 避免宠物、树叶和车辆造成误触发。
5. 关注灯头角度调节结构。
6. 关注散热、防水和防雷。
7. 太阳能款需要测试连续阴雨天续航。
8. 智能款需要考虑蓝牙、Wi-Fi、APP 和 OTA 功能。

5. 关注灯罩材料的抗 UV 能力。
6. 考虑产品是否需要拆卸和收纳。
7. 如果采用电池供电，需要测试续航能力。
