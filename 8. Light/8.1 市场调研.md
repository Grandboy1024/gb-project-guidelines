# 市场调研

以 Amazon 美国站为例，需要研究：
- 同类产品有哪些品牌？
- 市场售价是多少？
- 销量和评论数量如何？
- 用户最常抱怨什么？
- 竞争产品有哪些功能？
- 哪些功能值得做差异化？

# 维度

| 调研项目 | 具体内容 |
| :--- | :--- |
| 产品类型 | Solar Light、Flood Light、Wall Light 等 |
| 光学参数 | 流明、色温、显色指数、照射角度 |
| 电源 | 太阳能、电池、AC 供电 |
| 通信 | Bluetooth、Wi-Fi、Zigbee |
| 智能功能 | APP、定时、场景、亮度调节 |
| 竞争价格 | 售价、优惠、套装数量 |
| 用户反馈 | 续航、防水、感应距离、连接稳定性 |

# 产品需求文档

确定产品的完整规格。

例如，一款 Wi-Fi + Bluetooth 智能户外灯：

| 模块 | 需要定义的内容 |
| :--- | :--- |
| 光源 | LED 数量、功率、流明、色温 |
| 电源 | AC/DC、电池容量、太阳能板 |
| 控制 | 开关、亮度、模式 |
| 传感器 | PIR 人体感应、光敏传感器 |
| 通信 | Wi-Fi 2.4GHz + Bluetooth |
| APP | 添加设备、控制、定时、场景 |
| 固件 | OTA、配网、设备状态 |
| 防护 | IP65/IP66 |
| 安全 | 过流、过压、过温保护 |

输出文件：
- 产品需求文档（PRD）
- 产品规格书（Product Specification）
- 产品功能清单（Feature List）
- 竞品分析报告
- 目标成本表
- 初步产品外观设计
