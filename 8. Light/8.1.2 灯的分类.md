# 灯具产品分类及应用场景指南


## 一、文档目的

本文档用于建立灯具产品分类体系，帮助产品经理、研发人员和项目负责人了解不同灯具的类型、适用场景、核心技术参数及开发注意事项。

适用范围：
- 灯具产品规划与市场调研
- 灯具硬件及结构设计
- LED 光学设计
- 嵌入式固件开发
- 智能灯 APP 功能规划
- 产品测试与质量控制
- 美国市场产品开发与销售

灯具产品可以从以下五个维度进行分类：

1. 使用场景
2. 供电方式
3. 控制方式
4. 照明功能
5. 产品智能化程度

# 二、按照使用场景分类

## 2.1 室内照明（Indoor Lighting）

### 2.1.1 筒灯 / 射灯（Recessed Downlight / Spotlight）

**适用场景：**
- 客厅
- 卧室
- 厨房
- 走廊
- 办公室
- 商业展示空间

**产品特点：**
- 通常嵌入天花板安装
- 外观简洁
- 可以提供基础照明或重点照明
- 部分产品支持角度调节
- 可以支持调光、调色温

**核心参数：**
- 光通量（Luminous Flux，lm）
- 输入功率（Input Power，W）
- 光效（Luminous Efficacy，lm/W）
- 色温（CCT，K）
- 显色指数（CRI）
- 光束角（Beam Angle，°）
- 开孔尺寸（Cutout Size）
- 安装深度（Installation Depth）

**开发注意事项：**
- 确认天花板开孔尺寸
- 确认灯具安装深度
- 关注散热结构
- 控制眩光
- 确认调光器兼容性
- 关注灯具与驱动电源的匹配

### 2.1.2 吸顶灯（Ceiling Light / Flush Mount）

**适用场景：**
- 卧室
- 厨房
- 卫生间
- 走廊
- 客厅
- 办公室

**产品特点：**
- 安装在天花板表面
- 通常提供较大范围的基础照明
- 结构相对简单
- 可以支持调光和调色温
- 适合开发智能照明产品

**核心参数：**
- 光通量（lm）
- 功率（W）
- 光效（lm/W）
- 色温（K）
- 显色指数（CRI）
- 发光角度
- 灯具直径
- 安装方式
- 防护等级（IP Rating）

**开发注意事项：**
- 关注整灯散热
- 控制灯具厚度
- 关注光线均匀性
- 避免明显暗区和眩光
- 确认安装底座兼容性
- 做长时间点亮测试

### 2.1.3 吊灯（Pendant Light / Chandelier）

**适用场景：**
- 餐厅
- 客厅
- 玄关
- 吧台
- 商业空间

**产品特点：**
- 具有较强装饰属性
- 通常采用吊装方式
- 可以兼顾装饰照明和基础照明
- 外观设计对产品竞争力影响较大

**核心参数：**
- 光通量（lm）
- 功率（W）
- 色温（K）
- 显色指数（CRI）
- 吊装高度
- 灯具尺寸
- 灯罩材料
- 调光范围

**开发注意事项：**
- 确保吊装结构可靠
- 关注灯具重量和承重
- 设计合理的电线长度
- 关注灯罩材料的耐热性能
- 考虑调光和智能控制兼容性

### 2.1.4 LED 灯带 / 橱柜灯（LED Strip / Under Cabinet Light）

**适用场景：**
- 厨房橱柜
- 衣柜
- 楼梯
- 电视背景墙
- 展示柜
- 家居装饰

**产品特点：**
- 线性发光
- 安装方式灵活
- 部分灯带支持裁剪
- 可以实现 RGB、RGBIC 等彩色效果
- 适合开发智能灯产品

**核心参数：**
- 每米光通量（lm/m）
- 每米功率（W/m）
- LED 数量（LEDs/m）
- 工作电压（V）
- 灯带长度（m）
- 色温（K）
- 显色指数（CRI）
- 防护等级（IP Rating）

**开发注意事项：**
- 注意长距离供电压降
- 确认供电电压
- 合理设计电源功率
- 关注灯珠密度和发光均匀性
- 关注粘胶耐久性
- 考虑灯带散热
- RGBIC 需要考虑独立像素控制和数据传输

### 2.1.5 落地灯 / 台灯（Floor Lamp / Table Lamp）

**适用场景：**
- 阅读
- 床头照明
- 办公桌
- 客厅
- 书房
- 局部氛围照明

**产品特点：**
- 可以移动
- 适合局部照明
- 部分产品支持多角度调节
- 可以集成触摸、遥控、蓝牙或 Wi-Fi 控制

**核心参数：**
- 光通量（lm）
- 照度（lux）
- 色温（K）
- 显色指数（CRI）
- 调光范围
- 灯头角度
- 底座尺寸
- 输入功率（W）

**开发注意事项：**
- 关注底座稳定性
- 防止倾倒
- 控制眩光
- 关注灯头调节结构
- 考虑触摸按键设计
- 确认 USB 供电或交流供电方案

## 2.2 室外照明（Outdoor Lighting）

### 2.2.1 太阳能感应灯（Solar Motion Sensor Light）

**适用场景：**
- 房屋外墙
- 车库入口
- 后院
- 庭院
- 仓库
- 户外通道

**产品特点：**
- 太阳能供电
- 内置可充电电池
- 通过人体感应自动点亮
- 通常支持光控
- 部分产品支持遥控器
- 部分产品支持蓝牙或 Wi-Fi

**核心参数：**
- 光通量（lm）
- LED 数量
- 太阳能板功率（W）
- 电池容量（mAh / Wh）
- 电池电压（V）
- 充电时间
- 工作续航时间
- PIR 感应距离（m）
- PIR 感应角度（°）
- IP 防护等级
- 灯具照射角度

**开发注意事项：**
- 太阳能板功率需要与电池容量匹配
- 关注阴雨天气下的续航能力
- 明确不同亮度模式的工作时间
- 优化 PIR 感应距离和角度
- 避免树叶、宠物等造成误触发
- 关注电池充放电保护
- 做高低温测试
- 做防水和长期户外老化测试

### 2.2.2 安防泛光灯（Security Floodlight）

**适用场景：**
- 车道
- 车库
- 房屋周边
- 仓库
- 停车区域
- 户外安防区域

**产品特点：**
- 高亮度
- 大范围照明
- 可以采用多个灯头
- 可以搭配人体感应器
- 部分产品支持摄像头联动

**核心参数：**
- 光通量（lm）
- 输入功率（W）
- 光束角（Beam Angle）
- 峰值光强（cd）
- 照射距离
- 感应距离
- 感应角度
- 延迟时间
- 色温（K）
- IP 防护等级

**开发注意事项：**
- 不能只关注 LED 数量
- 需要测试整灯实际输出流明
- 关注光束角和照射范围
- 关注灯头角度调节
- 关注散热设计
- 做防水和防雷评估
- 优化感应器抗干扰能力

### 2.2.3 景观灯 / 地插灯（Landscape Light / Spotlight）

**适用场景：**
- 花园
- 草坪
- 树木
- 景观墙
- 庭院装饰
- 户外建筑装饰

**产品特点：**
- 主要用于局部照明和装饰
- 可以采用地插安装
- 可以采用固定式安装
- 部分产品支持 RGB 彩色照明

**核心参数：**
- 光通量（lm）
- 光束角（°）
- 色温（K）
- 显色指数（CRI）
- 工作电压（V）
- 功率（W）
- IP 防护等级
- 灯具安装深度

**开发注意事项：**
- 关注光束角
- 关注地插结构强度
- 关注户外耐腐蚀能力
- 关注防水密封
- 考虑太阳光照对外壳材料的影响
- 避免光线直接照射人眼

### 2.2.4 太阳能路径灯（Solar Pathway Light）

**适用场景：**
- 花园小路
- 人行道
- 草坪边缘
- 庭院
- 户外步道

**产品特点：**
- 太阳能供电
- 自动夜间点亮
- 通常功耗较低
- 安装简单
- 适合批量
