# 阶段 7：正式上市与运营

产品上架只是开始。

上市后需要持续关注：

| 工作 | 具体内容 |
| :--- | :--- |
| 广告 | Sponsored Products 等广告 |
| SEO | 关键词优化 |
| 评价 | 分析客户反馈，合规获取评价 |
| 库存 | FBA 库存和补货计划 |
| 售后 | 退换货、故障处理 |
| APP | 崩溃率、连接成功率 |
| 固件 | Bug 修复、OTA |
| 产品 | 根据差评持续改进 |

智能硬件和普通商品的一个重要区别是：售后不仅涉及商品本身，还涉及 APP、网络、固件、服务器。

因此，公司必须建立一个完整的售后故障分类体系，例如：
- 灯具无法开机。
- APP 无法发现设备。
- 蓝牙配网失败。
- Wi-Fi 连接失败。
- 远程控制失败。
- 设备离线。
- OTA 升级失败。
- 灯具亮度异常。
