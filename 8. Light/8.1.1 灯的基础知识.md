# 一、文档
智能灯产品技术参数知识手册

# 二、光学参数（Optical Specifications）

光学参数决定灯具的亮度、照射范围、光线颜色及照明质量。

| 英文名称 | 中文名称 | 单位 | 说明 |
|---|---|---|---|
| Luminous Flux | 光通量 | lm | 总光量 |
| Illuminance | 照度 | lx | 实际接收光量 |
| Beam Angle | 光束角 | ° | 光线扩散范围 |
| CCT | 色温 | K | 光线冷暖 |
| CRI / Ra | 显色指数 | 无量纲 | 颜色还原能力 |
| R9 | 饱和红色显色指数 | 无量纲 | 红色还原能力 |
| Flicker | 频闪 | % / 指数 | 光输出波动 |
| Luminous Efficacy | 光效 | lm/W | 单位功率光通量 |
| UGR | 统一眩光值 | 无量纲 | 眩光评价 |
| Light Distribution | 配光曲线 | — | 光线空间分布 |


## 2.1 光通量（Luminous Flux）

光通量（Luminous Flux）表示光源在单位时间内发出的可见光总量，单位：lm（Lumen，流明）。

常见参数，数值越大，表示灯具发出的总光量越多：
- 400 lm
- 800 lm
- 1500 lm
- 2500 lm
- 5000 lm
- 10000 lm

注意：光通量不等于实际照射效果，还需要结合光束角、配光曲线、照射距离等参数判断。

## 2.2 照度（Illuminance）

照度（Illuminance）表示单位面积接收到的光通量，单位：lx（Lux，勒克斯）。

计算关系：`1 lx = 1 lm/m²`，常见测试位置：
- 1 米处照度
- 3 米处照度
- 5 米处照度
- 地面照度
- 工作平面照度

注意：照度会受到灯具光学结构、光束角、安装高度和测量位置影响。

## 2.3 光束角（Beam Angle）

光束角（Beam Angle）表示灯具光线扩散的角度。

常见范围：
- 15°～30°：窄光束
- 30°～60°：中等光束
- 60°～120°：宽光束

应用：
- 聚光灯：通常需要较小光束角。
- 泛光灯：通常需要较大光束角。
- 户外照明：需要根据安装位置和覆盖范围选择。

注意：需要区分光学光束角与灯具机械旋转角度。

## 2.4 色温（Correlated Color Temperature，CCT）

色温（Correlated Color Temperature，CCT）表示光源视觉上的冷暖程度，单位：K（Kelvin）。

常见色温：
| 色温 | 光线效果 |
|---|---|
| 1800K | 蜡烛色 |
| 2700K | 暖黄光 |
| 3000K | 暖白光 |
| 4000K | 自然白光 |
| 5000K | 冷白光 |
| 6000K | 偏冷白光 |
| 6500K | 日光色 |

常见应用：
- 家居照明：2700K～4000K。
- 办公照明：4000K～5000K。
- 户外安全照明：5000K～6500K。

## 2.5 显色指数（Color Rendering Index，CRI）

显色指数（Color Rendering Index，CRI）衡量光源还原物体真实颜色的能力。

常见等级：
| CRI | 显色效果 |
|---|---|
| Ra 70 | 一般 |
| Ra 80 | 常见照明水平 |
| Ra 90 | 较高显色 |
| Ra 95 | 高显色 |

数值越高，通常颜色还原能力越好。

## 2.6 特殊显色指数（R9）

特殊显色指数（R9）用于衡量光源还原饱和红色的能力。普通 CRI 主要采用 R1～R8 的平均值，因此不能仅凭 Ra 判断红色还原效果。对于需要高显色质量的照明产品，可以额外关注 R9。

## 2.7 频闪（Flicker）

频闪（Flicker）表示光源输出随时间变化的波动情况。不能仅通过肉眼判断是否存在频闪，需要使用专业设备测试。

常见评价指标：
| 参数 | 含义 |
|---|---|
| Flicker Percentage | 频闪百分比 |
| Flicker Index | 频闪指数 |
| PstLM | 短期光闪烁指标 |
| SVM | 频闪效应可见度指标 |


## 2.8 光效（Luminous Efficacy）
光效越高，代表单位功率产生的光通量越多。

计算公式：`光效（lm/W） = 光通量（lm）÷ 输入功率（W）`

```
一款灯具，光通量：2500 lm，功率：25 W

光效：2500 ÷ 25 = 100 lm/W
```

# 三、电气参数（Electrical Specifications）

电气参数决定灯具的供电方式、功耗、驱动效率及电气安全。

## 3.1 额定电压（Rated Voltage）

- 单位：V（Volt）
- 定义：产品设计正常工作的额定输入电压。

常见规格：

- 5V DC
- 12V DC
- 24V DC
- 120V AC
- 100～240V AC

美国市场常见市电输入为 120V AC、60Hz，但产品设计应根据目标市场的电网条件确定。

## 3.2 输入电压范围（Input Voltage Range）

表示产品允许工作的电压范围。

例如：

100～240V AC，50/60Hz。

适用于需要兼容不同国家电网的产品。

## 3.3 额定功率（Rated Power）

- 单位：W（Watt）

表示灯具正常工作时的额定功耗。

常见规格：

- 10W
- 20W
- 30W
- 50W
- 100W

注意：

功率越高不代表亮度一定越高，需要结合 LED 光效和光学损耗判断。

## 3.4 输入电流（Input Current）

输入电流（Input Current）表示产品从电源获取的电流，单位：A（Ampere）。

例如：

120V AC、30W 的灯具，其输入电流需要结合功率因数和电源效率计算。

## 3.5 输出电压（Output Voltage）

输出电压（Output Voltage）表示 LED 驱动器输出端提供的电压。常见于 LED Driver 规格书。

## 3.6 输出电流（Output Current）

输出电流（Output Current）表示 LED 驱动器向 LED 灯板提供的电流。对于恒流驱动方案，输出电流是重要设计参数。

## 3.7 功率因数（Power Factor，PF）

功率因数（Power Factor，PF）表示交流输入侧的有功功率与视在功率之间的关系。PF 越接近 1，通常表示功率因数越高。

## 3.8 电源效率（Power Supply Efficiency）

电源效率（Power Supply Efficiency）输出有功功率与输入有功功率的比值，单位：%。效率越高，电源自身损耗通常越低。

## 3.9 待机功耗（Standby Power）

待机功耗（Standby Power）表示灯具关闭但仍处于待机状态时消耗的功率，单位：W。智能灯需要重点关注，因为 Wi-Fi、Bluetooth 和 MCU 可能持续运行。

## 3.10 总谐波畸变（Total Harmonic Distortion，THD）

总谐波畸变（Total Harmonic Distortion，THD）用于评价电流或电压波形中谐波成分的情况，单位：%。

## 3.11 浪涌保护（Surge Protection）

浪涌保护（Surge Protection）用于评价产品抵抗瞬态过电压冲击的能力，单位：kV。户外灯具尤其需要关注雷电感应、电网切换等引起的浪涌风险。

## 3.12 LED 驱动方式

常见驱动方式：

| 英文名称 | 中文名称 | 说明 |
|---|---|---|
| Constant Current | 恒流驱动 | 输出电流保持稳定 |
| Constant Voltage | 恒压驱动 | 输出电压保持稳定 |
| PWM Dimming | PWM 调光 | 通过脉冲控制亮度 |
| Analog Dimming | 模拟调光 | 通过模拟信号调节 |
| 0-10V Dimming | 0-10V 调光 | 常见于商业照明 |
| TRIAC Dimming | 可控硅调光 | 常用于兼容调光电路的交流灯具 |
| DALI Dimming | DALI 调光 | 数字化照明控制协议 |

# 四、LED 光源参数（LED Specifications）

## 4.1 LED 类型（LED Type）

常见 LED 封装：

| 封装 | 常见用途 |
|---|---|
| 2835 | 普通照明 |
| 3030 | 中高功率照明 |
| 5050 | RGB、彩色照明 |
| 3528 | 灯带及装饰照明 |
| COB | 集成式光源 |

注意：封装型号不代表固定功率和亮度，具体参数需要参考 LED 厂商 Datasheet。

## 4.2 LED 数量（LED Quantity）

LED 数量（LED Quantity）表示灯具中安装的 LED 数量。

例如：

- 60 LEDs
- 100 LEDs
- 210 LEDs

LED 数量不能直接代表灯具亮度，需要结合单颗 LED 的光通量、工作电流和光学损耗判断。

## 4.3 LED 正向电压（Forward Voltage，Vf）

LED 正向电压（Forward Voltage，Vf）表示 LED 正向导通时两端的电压。

## 4.4 LED 正向电流（Forward Current，If）

LED 正向电流（Forward Current，If）表示 LED 正常工作时的正向电流。

## 4.5 LED 结温（Junction Temperature，Tj）

LED 结温（Junction Temperature，Tj）表示 LED 芯片内部 PN 结的温度。结温过高可能影响 LED 光效、寿命和可靠性。

## 4.6 LED 分档（LED Binning）

常见分档：
- 光通量分档。
- 色温分档。
- 色坐标分档。
- 正向电压分档。

同一批产品尽量使用一致的 LED 分档，以减少亮度和颜色差异。

# 五、结构与环境参数（Mechanical & Environmental Specifications）

## 5.1 防护等级（IP Rating）

IP Rating 用于描述外壳对固体异物和水进入的防护能力。

例如：IP65。

- 第一个数字 6：完全防止粉尘进入。
- 第二个数字 5：防止来自各方向的喷水造成有害影响。

常见等级：

| 等级 | 说明 |
|---|---|
| IP44 | 防止规定尺寸固体异物及溅水 |
| IP54 | 防尘及防溅水 |
| IP65 | 防尘及防喷水 |
| IP66 | 防尘及防强烈喷水 |
| IP67 | 防尘及规定条件下短时浸水 |
| IP68 | 防尘及规定条件下持续浸水 |

IP 等级需要经过相应测试，不应仅凭产品结构判断。

## 5.2 抗冲击等级（IK Rating）

抗冲击等级（IK Rating）用于表示外壳抵抗机械冲击的能力。

常见等级：

IK06、IK07、IK08、IK09、IK10。

## 5.3 工作温度（Operating Temperature）

工作温度（Operating Temperature）表示产品正常工作的环境温度范围。

例如：

-20°C～50°C。

## 5.4 存储温度（Storage Temperature）

表示产品在不工作的情况下允许存储的环境温度范围。

## 5.5 外壳材料（Housing Material）

常见材料：

| 材料 | 特点 |
|---|---|
| Aluminum | 散热性能较好 |
| ABS | 常见工程塑料 |

| Glass | 玻璃 |
| Stainless Steel | 不锈钢 |
| Die-cast Aluminum | 压铸铝 |

## 5.6 其他结构参数

# 六、电池与太阳能参数（Battery & Solar Specifications）

适用于太阳能灯、无线灯和电池供电灯具。

## 6.1 电池类型（Battery Chemistry）

常见电池：

- Lithium-ion：锂离子电池。
- LiFePO4：磷酸铁锂电池。
- NiMH：镍氢电池。
- NiCd：镍镉电池。

不同电池在电压、能量密度、循环寿命、安全性和温度适应性方面存在差异。

## 6.2 电池容量（Battery Capacity）

- 单位：mAh / Ah

例如：

- 2000mAh
- 4000mAh
- 5000mAh
- 10000mAh

表示电池的电荷容量。

## 6.3 电池能量（Battery Energy）

- 单位：Wh

计算公式：

电池能量（Wh）= 电池电压（V）× 电池容量（Ah）

例如：

3.7V × 5Ah = 18.5Wh。

Wh 比单独使用 mAh 更适合比较不同电压的电池能量。

| Charging Time | 充电时间 | h |
| Discharging Time | 放电时间 | h |
| Charge Current | 充电电流 | A |
| Discharge Current | 放电电流 | A |
| BMS | 电池管理系统 | — |
| Battery Protection | 电池保护 | — |

## 6.5 太阳能板参数（Solar Panel Specifications）

| 英文名称 | 中文名称 | 单位 |
|---|---|---|
| Solar Panel Power | 太阳能板功率 | W |
| Solar Panel Voltage | 太阳能板电压 | V |
| Solar Panel Current | 太阳能板电流 | A |
| Conversion Efficiency | 光电转换效率 | % |
| Panel Dimensions | 面板尺寸 | mm |
| Charging Efficiency | 充电效率 | % |

## 6.6 太阳能灯续航计算

假设：

- 电池电压：3.7V
- 电池容量：5000mAh
- 灯具平均功率：2W

电池理论能量：

3.7 × 5 = 18.5Wh

理论工作时间：

18.5 ÷ 2 = 9.25h

实际续航还需要考虑：

- 电池放电效率。
- 驱动电源损耗。
- 电池保护余量。
- 环境温度。
- 电池老化。
- 不同亮度下的功耗。

需要了解：

- MCU Manufacturer：芯片厂商。
- MCU Model：芯片型号。
- CPU Frequency：主频。
- Flash：闪存容量。
- RAM：运行内存。
- GPIO：通用输入输出接口。
- ADC：模数转换接口。
- PWM：脉宽调制接口。

| ENERGY STAR | ENERGY STAR Program | 适用产品能源认证 |
| RoHS | Restriction of Hazardous Substances | 有害物质限制 |
| UN38.3 | Lithium Battery Transport Testing | 锂电池运输测试 |

注意：

并非所有产品都需要全部认证。

需要根据以下因素确认：

1. 产品供电方式。
2. 产品安装方式。
3. 是否使用无线通信。
4. 是否包含锂电池。
5. 产品具体用途。
6. 美国联邦及州级法规。
7. Amazon 对具体 ASIN 的审核要求。
