# 阶段 6：Amazon 美国站销售准备

产品做好了，不代表可以马上销售。还需要准备品牌、账号、物流和销售资料。

## 6.1 品牌建设

建议提前完成：
- 品牌名称。
- 商标注册（美国市场建议评估 USPTO 商标注册）。
- 品牌 LOGO。
- 产品包装视觉设计。
- 品牌官网。
- 售后邮箱。
- 品牌故事。

如果符合条件，可以进一步申请 Amazon Brand Registry。

## 6.2 亚马逊店铺

需要准备：
- Amazon Seller Central 卖家账号。
- 公司注册资料。
- 身份和地址验证资料。
- 收款账户。
- 信用卡。
- 税务信息。
- 产品责任保险（达到适用要求时）。

## 6.3 产品 Listing

每款产品需要准备：

| 内容 | 具体要求 |
| :--- | :--- |
| 产品标题 | 产品类型、核心功能、关键参数 |
| 主图 | 白底产品图 |
| 副图 | 功能、尺寸、安装、场景 |
| 视频 | 产品演示视频 |
| 五点描述 | 5 个主要卖点 |
| A+ 页面 | 品牌和产品详细介绍 |
| 产品说明书 | 英文版 |
| FAQ | 常见问题 |
| 售后信息 | 联系方式、质保政策 |

## 6.4 物流与库存

需要提前规划：
- 国内仓库。
- 出口报关。
- 国际运输。
- 美国进口清关。
- 美国 FBA 仓库。
- FNSKU 标签。
- 外箱标签。
- 包装尺寸和重量。
- FBA 仓储及配送成本。

建议第一批产品不要盲目备货，先通过小批量库存验证市场需求。
